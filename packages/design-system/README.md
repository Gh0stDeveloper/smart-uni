# Sistema de diseño de SMART UNI

Conservamos el icono original del birrete azul/turquesa, Poppins y Roboto, menú unificado, pantallas limpias y sin panel adicional a la derecha. Las futuras variantes Android y escritorio seguirán estos criterios.

Los recursos SVG y tokens de la versión existente se conservan dentro del prototipo de escritorio; más adelante centralizaremos aquí una única fuente de verdad y su posible sincronización con Figma.
