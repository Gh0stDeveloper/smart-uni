# 8.1 Interfaz nativa Java — segunda integración

## Implementación en `main`

La aplicación Android conserva icono de birrete y paleta SMART UNI, sin panel lateral redundante. La navegación contiene Inicio, Apuntes, Tareas, Calendario, Materiales y Perfil; los cuatro módulos de contenido ya no muestran solamente avisos de "próximamente":

- **Apuntes:** múltiples notas locales con título, contenido, edición y eliminación. El apunte de la primera iteración se importa sin eliminar el archivo cifrado antiguo.
- **Tareas:** creación, lista, estado completado/pendiente y eliminación con persistencia cifrada local.
- **Calendario:** creación de eventos con selección de fecha mediante Android DatePicker, lista y eliminación.
- **Materiales:** selección mediante Storage Access Framework, almacenamiento privado de archivo cifrado mediante Rust, eliminación y lectura interna de TXT/MD/CSV. Se rechazan extensiones ajenas y archivos mayores de 8 MiB. No se abren PDF/Office/imágenes en visores externos todavía.
- **Perfil:** sigue señalando sesión desconectada; diagnóstico HTTPS público sin credenciales, sin simulación de sincronización.

Todos los registros viven en `LocalVault.java` como JSON **dentro de un contenedor Rust AES-256-GCM** con context AAD distinto del apunte legacy. El fichero cifrado se sustituye mediante `AtomicFile`. **No es SQLite/SQLCipher** y no contiene tablas ni outbox multientidad transaccional.

## Limitaciones y criterios pendientes

La interfaz y sus textos no se han verificado con TalkBack ni en pantallas físicas pequeñas/tablets; sigue faltando calendario con horas/repeticiones, tareas enriquecidas, previsualización segura de PDF/Office/imágenes, búsqueda, tests de rendimiento y edición concurrente multi-proceso. La importación de material escribe archivo y metadata en dos operaciones y puede dejar ciphertext huérfano si se interrumpe; hace falta recuperación/GC transaccional. La bóveda tiene límite 512 KiB de metadata y 400 elementos por categoría.

No se incorporó navegación de cuenta activa, datos de demostración fraudulentos ni sync automática. El modo E2EE multiplataforma continúa pendiente de OIDC y enrolamiento.
