# 8.1 Interfaz nativa Java

## Implementación

Proyecto Gradle Android en `apps/android`, Activity Java accesible, scroll y navegación táctil entre Inicio, Apuntes, Tareas, Calendario, Materiales y Perfil. Paleta `#2B80EC`, `#2BB2C4`, `#F3F7FC` desde `packages/design-system/tokens.json`; vector del birrete reproducido de `apps/desktop/design/figma_svg/00_isotipo_smart_uni.svg`. Sin panel lateral redundante. Área central con límite de anchura para tablets.

**Funcionalidad real:** un único apunte editable guardado en disco privado mediante Rust/Keystore, independiente de Internet. Inicio muestra estado del núcleo; Perfil muestra que no hay sesión y permite diagnóstico HTTPS público sin credenciales. Las otras pantallas se identifican como pendientes y no fabrican contenido.

## Criterios medibles

- Build Android `assembleDebug` e instrumentación en emulador API 35.
- Verificar foco, lectura por TalkBack, textos y contraste en teléfono/tablet físicos durante beta; esas evidencias aún NO existen.
- Verificar que en ausencia de biblioteca Rust la operación de almacenamiento falle cerrado.
- No hay equivalencia funcional con escritorio ni navegación automática a cuentas reales.

**Resultado:** estructura y pantallas iniciales implementadas. Validación de diseño y accesibilidad física pendiente. Ver [acta](8_CIERRE_Y_EVIDENCIAS.md).
