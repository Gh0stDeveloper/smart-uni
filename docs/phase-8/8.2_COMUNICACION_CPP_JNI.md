# 8.2 Comunicación C++/JNI

## Implementado

`apps/android/app/src/main/cpp/bridge.cpp` y `CMakeLists.txt` implementan el adaptador Java ↔ JNI C++ ↔ Rust. Las rutas de diagnóstico residen en C++ (`GET /healthz`), no Java. Se invoca la pila TLS y validación de certificado/hostname **oficial de Android** por JNI, sin TrustManager personalizado, sin permitir HTTP y sin seguir redirecciones. No hay secretos del servidor en Java, C++ o Rust.

C++ comprueba longitudes de buffers, devuelve `null` ante fallos criptográficos sin sustituir por claro y limpia de forma best-effort sus buffers sensibles. Rust no confía en cadenas de cliente para determinar propiedad de registros.
