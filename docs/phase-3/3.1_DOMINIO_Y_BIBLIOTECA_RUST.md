## 3 Núcleo compartido en Rust

### 3.1 Dominio y biblioteca Rust

**Objetivo del ROADMAP:** implementar lógica compartida con pruebas y versiones, sin sustituir prematuramente el prototipo.

**Código real** (crate `smartuni-core` 0.1.0, Rust edition 2021):
- `core/rust/src/lib.rs`: versiones `CORE_VERSION`, contrato `1.0.0`, almacenamiento legado `version=1` y módulos públicos.
- `core/rust/src/domain.rs`: `normalize_email` y `validate_student` independientes de la UI; el retorno no incluye contraseñas ni otorga autenticación. El dominio Rust impone un límite de 254 bytes en email, mientras la validación anterior Python no lo hacía; para entradas normales existe equivalencia, pero **no se asegura equivalencia absoluta**.
- `core/rust/src/contracts.rs`: parseo estricto JSON con versión conocida, hasta 1 MiB, operaciones enumeradas, IDs hex de 128 bits, timestamp RFC3339 y payload tipo objeto. Rechaza versiones superiores, entradas incompletas y campos desconocidos.
- Los contratos v1 del repositorio siguen en `packages/contracts/v1/`. La implementación no envía operaciones ni autoriza recursos. `actor_ref` es referencia no autenticada.

**Pruebas reproducibles (Windows/Linux):**
`cargo fmt --manifest-path core/rust/Cargo.toml --all -- --check`;
`cargo test --manifest-path core/rust/Cargo.toml --all-targets`;
`cargo clippy --manifest-path core/rust/Cargo.toml --all-targets -- -D warnings`.
El flujo [Núcleo Rust](https://github.com/Gh0stDeveloper/smart-uni/actions/workflows/rust-core.yml) ejecuta estas pruebas; sus resultados y commit final se registran en el acta de cierre.

**Compatibilidad:** los servicios Python conservan registro, login local, JSON v1 y sus importaciones. Este crate todavía no está conectado al inicio de sesión; su uso desde Python es explícito mediante el adaptador de 3.2. No se ha migrado la contraseña PBKDF2 ni se introdujo Argon2id.

**Criterios:** código real, validación de contratos versionados, pruebas Rust en Windows/Linux y ausencia de modificaciones visuales verificadas en la suite existente.
