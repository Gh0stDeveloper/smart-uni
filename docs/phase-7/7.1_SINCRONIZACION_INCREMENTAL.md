# 7 Sincronización multiplataforma — 7.1 Sincronización incremental

## 7 Sincronización multiplataforma

### 7.1 Push/pull incremental seguro

**Alcance implementado:** services/api/app/sync_api.py (FastAPI + PostgreSQL 16) y apps/desktop/smart_uni/encrypted_sync.py (SQLCipher + Rust). Cliente opt-in probado con dos instalaciones de laboratorio. No está conectado al login OIDC real de la UI Tkinter, portal Next.js, cliente Android ejecutable o backend público; tampoco sincroniza automáticamente el JSON legacy.

**Flujo verificado:** el cliente recibe UUID propietario desde GET /api/v1/me y usa un bearer OIDC explícito y clave E2EE aprovisionada externamente. queue_change cifra mediante Rust AES-256-GCM SUAEAD01 y persiste solo ciphertext en SQLCipher, separado del outbox v1 (que puede contener JSON en claro). push_pending entrega contenedor y operation_id; FastAPI obtiene propietario del JWT y PostgreSQL, no de actor_ref. Un bloqueo de transacción por propietario serializa cursores y las revisiones CAS. Operación duplicada con mismos bytes devuelve ACK sin doble commit; mismo UUID con otros bytes se rechaza.

**Tolerancia a cortes:** un ACK perdido tras COMMIT deja el ciphertext pendiente y programa backoff persistido; siguiente reintento usa el mismo UUID. pull_next descarga versiones por cursor, comprueba secuencia y autentica cada ciphertext y tombstone con Rust antes de insertar inbox + cursor en una sola transacción SQLCipher. Una clave equivocada, mensaje alterado o interrupción entre operaciones conserva el cursor original y no pierde versiones.

**AAD obligatorio:** sync/{owner_uuid_hex}/{resource_uuid_hex}/epoch-{epoch}/base-{base_revision}/kind-{put|delete|blob}. El servidor comprueba el framing y contexto, pero no puede comprobar el tag criptográfico sin clave. El cliente sí lo comprueba. No hay claves privadas en API.

**Seguridad y pendientes:** los endpoints de notas en texto claro heredados están deshabilitados por defecto y solo se pueden reactivar expresamente para demos sintéticas. Los datos previos de esa tabla no se migraron. Falta OIDC desktop real, distribución de claves HPKE autenticada, implementación Android, sync automático de actividades del JSON/outbox v1, despliegue HTTPS y anti-rollback frente a un servidor malicioso.
