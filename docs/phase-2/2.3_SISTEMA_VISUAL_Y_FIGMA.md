# 2 Contratos y sistema de diseño — sistema visual y Figma

## 2 Contratos y sistema de diseño

### 2.3 Sistema visual y Figma

**Alcance implementado:** centralización de diseño y roles visuales sin crear pantallas nuevas.

| Entregable | Archivo | Evidencia |
|---|---|---|
| Fuente canónica | `packages/design-system/tokens.json` | Colores originales y Poppins/Roboto, nuevos nombres semánticos para roles antes locales |
| Copia portable | `apps/desktop/design/tokens.json` | Igualdad de bytes con la fuente compartida |
| Adaptador Tkinter | `apps/desktop/smart_uni/design_system.py` | UI consume tokens; `COLORS` y `FONT_*` preservan todos sus valores |
| Identidad | `packages/design-system/identity.json` | SHA de blob Git de PNG/SVG históricos y reglas de navegación |
| Automatización | `scripts/sync_design_tokens.py`, `scripts/check_design_system.py` | CI rechaza cambios involuntarios o desincronizaciones |
| Empaquetado | Scripts PyInstaller Windows/Linux y workflow de Windows | Incluyen PNG y tokens en los artefactos |
| Revisión Figma | `apps/desktop/docs/GUIA_FIGMA.md` | Procedimiento manual, sin conexión a API ni archivo externo |

**Regresión:** `tests/test_phase2_design_system.py` compara la paleta exacta de la línea base, tipografías, iconos por SHA y existencia de pantallas. Las capturas reales se generan por la suite desktop en Windows y Linux. No se declara comparación automática pixel a pixel ni acceso activo a Figma.

**Criterios de aceptación:**
- [x] Tokens y hashes de iconos centralizados con validación reproducible.
- [x] UI y scripts de empaquetado utilizan el recurso de tokens, conservando valores y recursos originales.
- [x] Guía de cambios Figma con revisión y aprobación, sin prometer integración.
- [x] 39/39 pruebas en Windows y Linux, capturas reales y respaldo sintético en [Actions #42162128163](https://github.com/Gh0stDeveloper/smart-uni/actions/runs/42162128163), contratos/diseño [#42162128182](https://github.com/Gh0stDeveloper/smart-uni/actions/runs/42162128182), Windows EXE [#42162128160](https://github.com/Gh0stDeveloper/smart-uni/actions/runs/42162128160) y nomenclatura [#42162128175](https://github.com/Gh0stDeveloper/smart-uni/actions/runs/42162128175) satisfactorios.
