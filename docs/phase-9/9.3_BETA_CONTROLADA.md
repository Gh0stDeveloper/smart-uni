## Endurecimiento del gate de evidencias

Además del checklist de 12 controles, `scripts/phase9_beta_gate.py` ahora exige el SHA de 40 caracteres de la revisión propuesta (`release_commit`) y, si toda la evaluación estructural está aprobada, consulta la API pública de GitHub Actions para verificar que cada evidencia corresponde a una ejecución completada con éxito **en `Gh0stDeveloper/smart-uni`, rama `main` y exactamente ese commit**. Fallos de red, ejecuciones inexistentes, resultados fallidos o SHAs no coincidentes bloquean el gate. Las pruebas usan respuestas sintéticas y comprueban aceptación y rechazos, no se atribuyen evidencias físicas inexistentes.

**Límite:** un run verde puede contener tests insuficientes o etiquetas falseadas; la identidad de `reviewed_by` tampoco es verificada por la API. El cotejo de dispositivos, videos/logs, identidad real del revisor y aprobación humana sigue siendo obligatorio. El checklist de ejemplo permanece bloqueado, sin autorizaciones automáticas de beta.
